# Asset Manifest

No binary or character assets are shipped in the Draft prototype.

Runtime text, geometry, colour tokens, and placeholder monograms are authored in
code. The Workshop UI pack is classified in the migration ledger but remains
deferred until its assets are required and individually approved.

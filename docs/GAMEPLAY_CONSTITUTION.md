# SINBIN Gameplay Constitution

These principles survive balance changes unless a dated decision explicitly
revises them.

1. **Substitution is the signature verb.** The player changes the machine while
   the hockey play remains alive.
2. **The puck and play state are primary.** Stamina and Pressure constrain the
   hockey problem; they do not replace it.
3. **Roles create sequences.** A specialist is valuable because of what it lets
   the roster do next, not because it carries a larger generic number.
4. **SHOOT creates a hockey chance.** Momentum is temporary offensive force;
   the player sees the resulting goal chance before choosing to shoot. Waiting
   can improve the chance, but a collapse loses the current play.
5. **Failure is legible.** The event log names the broken link or exhausted
   player and preserves enough evidence for an immediate retry.
6. **Coach Mode is not paused Live.** It uses the same hockey state and actions,
   but asks the player to answer finite opponent decision points.
7. **Live tests recognition and execution.** It runs the same hockey grammar
   under time pressure and remains the primary first-play experience.
8. **Opponents own visible defensive structure.** Forecheck, coverage, and goalie
   composure reshape substitutions; they must not make the signature action
   broadly undesirable.
9. **Builds change grammar before percentages.** Strong upgrades create new
   handoffs, routes, and finishes rather than only increasing totals.
10. **Equipment is hockey legible.** A stick should change a player's sequence,
    route, or trade-off before it adds a generic stat.
11. **Discipline is player-caused risk.** A penalty must follow visible, avoidable
    escalation—not an opaque random punishment.
12. **The rectangle gate remains real.** Content and polish do not compensate for
    an uninteresting core decision.
